Trace It: Procedures and Nested Loops

Two(2) procedures. Both take arguments, and both have a loop inside a loop where the inner loop depends on those arguments. Fill in the trace table a row at a time and check each row as you go.

How this works

Each problem gives you a procedure and one call. Work out what each parameter is set to, fill in the trace table one row per pass of the outer loop, then say what the procedure returns.

Note: fill in a whole row, then check it. Get it right and the row locks. Get it wrong twice and you can have that row — but work it out first. Being wrong on purpose is how this one sticks.
