Score It: Create Task Written Responses

You are the AP reader. Four(4) real submissions, names removed. Score each response 0, 1, or 2 using the rubric, and write one sentence on why.

The rubric

Question iii

Consider the first iteration included in the first code segment. Describe the conditions that will cause the body of the iteration statement to execute once.

Point 1
Says this can't happen: the loop is hard-coded to run from 1 to 4, so the body always runs four(4) times.
Point 2
Explains why the 1 to 4 never changes in this program: we are always comparing four-letter color codes.

Question iv

Consider the first code segment. Write a call to your procedure with specific argument(s) that you could use for testing this procedure. Describe the program functionality you are testing related to this call.

Point 1
Gives both arguments, Guess and Colors, as specific four-letter codes using r, o, y, g, b, v.
Point 2
Explains what that call tests and what it should report. Example: rgby and rgby should report 4 because every color is in the right spot.

Note: a written response is scored on the code segment the student submitted. The questions ask about a procedure.
